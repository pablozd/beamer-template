# Beamer template pablozd

Template de Beamer para presentaciones academicas, basado en `metropolis` y
adaptado para materiales de linguistica.

## Compilar

```sh
latexmk -lualatex main.tex
```

El archivo principal es `main.tex`. El tema vive en `beamerthemepablozd.sty` y
los paquetes compartidos en `zd-paquetes.sty`.
